# Daily Standup Workflow
1. Analyze the git commit history for the past 24 hours, or read recently completed tasks from `docs/` or ask the user what was done.
2. Ask the user for the Project Name if not already known.
3. Generate a daily standup update strictly using the following format:

Project: [Project Name]
a. What did you do
 [List of completed tasks]
b. What do you plan to do
 [List of planned tasks]
c. Blockers:
  - [Blockers or None]
d. Working hours: 8hrs

4. Output the final standup text so the user can easily copy it.
